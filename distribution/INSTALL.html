Pokemon Kanto

Game Boy Color fan adventure for ModRetro Chromatic.

On Your Chromatic

  1. Connect your Chromatic by USB with a supported writable homebrew cartridge.
  2. Follow the official DevDay quickstart. If activation is needed, use the ModRetro Updater. Enter activation codes only in that updater.
  3. In Codex with the ModRetro Chromatic plugin, select this release and ask it to inspect Pokemon-Kanto.gbc and discover your device.
  4. Check the exact device and the ROM's SHA-256 against release.json before approving the write.
  5. Wait for confirmed completion, then boot the cartridge. For a timeout or unknown result, check the original operation's status before doing anything else.

Before writing: the selected cartridge's game data will be erased, saves may be lost, and no backup is made. Explicitly acknowledge this before approving. This guide and assistant never flash automatically.

On Your Computer

Open Pokemon-Kanto.gbc in a Game Boy Color-compatible emulator. No build tools are needed. D-pad moves/selects, A confirms, B cancels, Start opens the field menu.

Start a new game for v0.3.0. Back up old saves; the expanded roster changes the save layout. This complete-campaign preview has not been runtime-playtested. Read the full installation notes for driver, platform, editing and verification details.
